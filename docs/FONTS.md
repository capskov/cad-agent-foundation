# Font packaging and Chinese drawing text

The public candidate excludes the supplied `hztxt.shx` and `hztxt_e.shx` binaries. Availability on download sites does not establish redistribution permission for the exact supplied files. No such permission was found during this review; this is unresolved provenance, not a finding that every HZTXT file infringes rights.

For an existing drawing, obtain required fonts from the drawing author or another licensed source and install them in AutoCAD's font search path. This project does not link to unofficial font packs or automatically download HZTXT. Font names remain in closed historical contracts; those pilots are not part of the supported public profile.

Autodesk documents `gbcbig.shx` as a simplified-Chinese Big Font. Its tutorial also describes `gbenor.shx` / `gbcbig.shx` for Chinese drawings. Users may use fonts in their legitimate AutoCAD installation, but this project does not redistribute them. A style change requires a working-copy check of glyphs, widths, bounds and placement; no automatic replacement is introduced here.

The existing Open Sans Condensed Light asset has embedded Copyright 2020 The Open Sans Project Authors and SIL Open Font License 1.1. It may remain with the applicable copyright and OFL text. It is not advertised as a comprehensive Chinese engineering font or a substitute preserving every SHX glyph and metric.

New Foundation text/callout creation uses database defaults; the current plan is not a complete font/style adaptation interface. An existing drawing needs an appropriate working default style. Font omission does not change execution logic, but Chinese display needs the targeted public-installation/case check before claiming it is validated.

Sources: [Autodesk Asian Big Fonts](https://help.autodesk.com/cloudhelp/2026/ENU/AutoCAD-Core/files/GUID-CBC3F683-06F3-4B9C-8747-D01F3C262956.htm), [Autodesk Chinese tutorial](https://damassets.autodesk.net/content/dam/autodesk/www/apac/zh-cn/images/AutoCAD-101.pdf), [Open Sans OFL](https://github.com/googlefonts/opensans/blob/main/OFL.txt).
