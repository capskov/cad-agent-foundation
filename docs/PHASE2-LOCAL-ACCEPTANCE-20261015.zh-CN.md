# 1.2.0-local.1 本地有界验收

2026-10-15。公开Release仍是1.1.0-rc.1；本文件记录本地第二阶段首批交付，不是整个A～P范围完成证明。

## 运行版本

- Windows x64 AutoCAD2026，实际原生进程报告.NET8.0.15。

## 实际通过

1. 新功能通过底座MCP完成：点/弧/椭圆/矩形；图层、颜色、线型、线宽；直线/圆/开放多段线修改；限定直线/圆偏移和镜像复制；关联填充图案；文字格式、尺寸文字、角度尺寸；原生表格/单元格；简单命名块定义/插入/属性；页面设置、原生PDF、DXF指定对象磁盘读取、保存。
2. 最终新增流程17个跟踪对象保存后，在全新只读CAD进程通过MCP核对全部对象摘要和布局页面设置一致，来源文件保护、正常停止。
3. 最终二进制复验原有合成流程：四种原生尺寸（8、5、3、6）、中文字体、边界/填充续改、引线调整、完整组旋转/缩放/复制/归档、图层和查询。原有17个跟踪对象另在新只读进程核对一致。
4. 原生拒绝/回滚：旧摘要、未知块属性tag、已有PDF拒绝覆盖、缺少关联引线、锁层；先创建临时线再因目标层不存在失败，整批确认回滚，既有对象及模型成员保护通过。
5. PDF独立解析单页A3，实测约420.158×297.039毫米；已渲染目视检查中文、90度尺寸、表格、属性B02、曲线与填充，无观察到的剪裁问题。DXF独立读取本轮指定Line/Circle，不将其推广为所有导出实体逐项验收。

所有图内新建/修改都走受控Foundation MCP；CLI负责同一底座安装、启动副本、部分保存入口及安全停止。未用直接COM脚本或任意Lisp替代图内写入；历史合成种子已存在，本轮未调用旧造图辅助通道。

## 尚有限制

各命令的类型/数量/关联/单位边界见[完整开发与能力清单](PHASE2-DEVELOPMENT-20261015.zh-CN.md)。没有全面放开动态块、MLeader、复杂布尔、通用删除、完整布局/外参/视图、跨图、毫米或其他宿主。

M1/M2已有受限发现和页面读取；M3限layout/extents与固定原生比例；M4只是当前布局设备/纸张原生校验，独立预览仍待开发；M5目前单张PDF，图像输出未完成。M6/M7后置。纸张毫米与模型米的比例换算应显式处理，不由底座猜测工程比例。

PDF驱动生成文件存在元数据/重复PageMode解析警告，原始警告保留；文件可独立读取和渲染。本轮没有自动重写文件掩盖警告，未穷尽输出比例/字体/纸张组合。

中间出现一次回执身份核对失败，原请求仅提交一次；随后查询同一请求确认已提交、验证通过并正常释放栅栏。底层原因没有完整定位，未宣称已修复；CLI新增有界原请求查询重试，期限届满保留unknown，不重放写入或强制解锁。

最终运行ZIP的摘要、私有证据目录、安装同步记录和本轮交接保存在本地交付摘要；不把工程图、日志、凭据或机器私有路径加入本运行包。专业Skill、既有私有底座、旧安装与全局MCP配置保持独立。
