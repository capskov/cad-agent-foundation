# 原始坐标、单位元数据、精度与出图字高

本地1.2.0-local.4在local.3基础上收尾单位处理。单位信息用于辅助Agent理解图纸、判断精度和制图方式，普通原坐标操作不以物理单位判断为前置条件。

## 原始数值执行

普通绘图、移动、复制、文字和标注操作使用`units: raw_drawing_units`。坐标、长度、字高、填充比例等按DWG原始数值执行；底座不主动换算、不缩放图形、不修改INSUNITS。模型坐标、工程尺寸含义、INSUNITS、纸面毫米和打印比例分别理解。显式scale命令仍按Agent给出的倍率执行。

`expected_insunits`为可选整数0..24；省略时，未知、无单位或与常见单位习惯不同的INSUNITS均不拒绝普通原坐标操作。任务明确需要核对时填写该值，底座在事务前核对，失配时无写入拒绝。显式填写null、字符串或非法值属于接口格式错误。只读接口继续返回`units_code`辅助元数据。

旧版`units: metres`保留原有INSUNITS=0或6约定，不做数值换算，也不重解释已记录的旧请求。新任务推荐原始单位模式；保存入口始终生成原始单位计划，不自动附加单位检查。图纸身份、请求归属、旧值摘要、事务、未知写入不重放等保护继续适用。

```json
{"schema":"foundation-drawing-plan-v1","source_role":"test","units":"raw_drawing_units","steps":[{"id":"line","op":"line","start":[0,0],"end":[1000,0],"layer":"0","color":7}]}
```

此例只是1000个绘图单位的线段，底座不会将其解释为1000米或1000毫米。

## 精度分工

- 数值计算采用原始数值；退化几何、角度和倍率的数值阈值不代表专业允许偏差。
- 常用几何数值读回比较的现有绝对界限为0.001个原始单位，面积为0.001平方绘图单位；部分角度/倍率有更小的专用阈值。身份、摘要和未授权属性变化仍按各自契约严格核对。
- 工程验收误差由用户、专业Skill或Agent按任务确定。不能把上述读回界限称为0.001米/平方米，也不能把既有道路面积误差指导直接套成坐标误差。

这些数值比较检查命令执行及读回一致性，不证明工程正确性。本轮复用现有回归检查米制与毫米制样例的创建、移动、复制、文字、尺寸、填充和保存；若未暴露必要缺陷，不引入随INSUNITS自动变化的容差或单位规则引擎。超大数值和极端几何仍受现有有界接口限制，未作全组合认证。

## 无单位与Agent理解

INSUNITS=0照常执行原坐标操作。Agent可依据尺寸样例、已有标注、图框等判断物理单位；不需要物理单位的任务直接继续。只有涉及必须准确换算的工程尺寸、打印比例或跨图操作且依据不足时才进一步确认；此说明不新增跨图功能。

结构详图通常可参考毫米习惯，道路平面图可参考米习惯，但不能仅凭图纸类型认定单位。INSUNITS与图纸注释中的单位不一致时，按任务证据理解，不能主动篡改元数据或工程尺寸。

## 通用出图指导

用户或Skill指定的样式、字高和比例优先。未指定时，Agent按实际图框、纸张和打印比例反算文字高度；普通汉字最终纸面优先2.5～3.5mm，小于2mm重点检查可读性，属于指导范围，不强制拒绝。例如A3横向纸宽420mm，不能把模型字高直接当作纸面毫米。

比例服务清晰表达，同时保持工程尺寸和正式比例正确。这些指导写入工作区、项目及运行包的AGENTS.md，并在MCP入口提供简要提示；不新增自动字体排版、自动单位推断或自动出图比例计算。

## 本轮范围及证据

local.2的INSUNITS=4实机记录属于历史证据；local.4的实际MVID、米/毫米/无单位验证和安装状态以本轮本地收尾记录为准。构建或旧版本通过不等同于新版本实机通过。

本轮不扩展PDF/DXF：两个输出分支仍有独立INSUNITS=0或6门槛，PDF页面范围仍仅layout/extents。不得以普通写入已放开推断输出限制也已解除。后续GitHub发布按独立版本发布说明执行。
