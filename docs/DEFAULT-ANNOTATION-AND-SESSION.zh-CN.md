# 默认尺寸样式与工作图续作

项目、图纸样例或专业 Skill 有明确要求时优先沿用。以下是道路土建断面在缺少特殊指定时的默认做法，由 Agent 看图定位置，底座执行明确参数。

- 先看同张图的相邻断面、样式和单位注记。相邻同类断面用 cm 时，尺寸数字写 125、350，图内统一注明单位 cm。实际比例未建立时不写比例值。
- 以最终纸面字高 H 为基准。按实际打印窗口、纸幅及所属视口比例反算模型字高，纸空间按实际出纸倍率反算。普通汉字优先取纸面 2.5～3.5 mm。横向尺寸线和两根尺寸界线用细线，线宽初值约 0.03H，均应弱于被标轮廓。两根界线各穿过横线约 0.5～0.65H。交点各画一条约 45° 的斜短划，其总长可从约 0.85～1.1H 试起，线宽约 0.04H。数字居中放在横线上方，预留约 0.2H 的可见间隙。按最终纸面核看，细节可随既有样式调整。
- 占地范围端点指向确认的范围。沿用两条竖界线、细横线和斜短划，文字用适当的范围标签。管名按引线 Skill 采用普通关联引线，斜段默认可从与水平 30～40° 试排，折点内角保持钝角，尾段水平。边坡数字离开交点，顺坡线放置。尺寸线和关联引线各用自己的画法。
- 近似尺寸按代表位置取值，明确中心距、边到边净距和承插口净距的区别。示意详图落纸放大率与工程数字分开处理。

同一阶段续改默认复用当前受控工作图。重新绑定并核对 PID、进程出生时间、插件身份、完整 DWG 路径和未决请求；对涉及的已有对象重新读摘要。用户仅做平移、缩放或切换布局时保留视图，按实际布局及图元身份判断能否继续，DBMOD 不单凭数值解释成对象修改。用户动过图时以当前图的真实状态为准。仅在目标换图、受控会话无法恢复或确需隔离时另建会话。

用户要求关闭旧会话时，精确确认对应的受控 PID 和工作 DWG，先核对是否有未决写入。须保存的旧工作图只存入原工作副本，核对回执后正常 stop。保持正在继续修改的会话和图纸打开。发布图通过已保存工作图另行交付，保留旧发布版本的备份。
