## 仍然存在的缺陷（未修，已记录）

1. `query` 的空间过滤遇到无 extents 的块参照会整单失败：
   `failed to query entities: spatial filter could not read geometric extents for handle 131015`（`tzblxx` 块）。一个坏块会让整次空间查询不可用。
2. `BlockReference` 元数据 `nested_geometry_coverage` 仍写 `not_read`，但 `read` 实际能返回嵌套几何；该字段误导，且 `query` 不会递归块内。
3. 嵌套几何受 `batch_scalar_limit` 限制：本次 `issue_count=1942`（截断），部分大多段线/块参照读不出，翻页也补不回。
4. 页大小固定 64，CLI 没有 `--geometry-limit`；大块需要 31 次请求。
5. `query` 只查模型空间，不查块内；要查块内必须 `read <块句柄> --geometry-offset`。
