# 报警与暂停分级（用户确认，2026-10-29）

目标：可读的字体替换不再反复锁住工程；执行安全问题保持保护。不要凭报警字样统一停工，也不要一律吞掉异常。

|等级|典型事项|动作|
|---|---|---|
|信息|单位元数据仅供辅助解释；原生重绘完成但瓦片稳定性尚未确认|如实记录，按任务查看；不因元数据本身暂停原坐标操作|
|报警，继续|保存时普通字体、大字体、SHX/TTF文件名、解析字形发生替换；文字仍可读，主要影响排版|回执保留 before/after，返回 warning、blocks_write=false、visual_review_required=true；继续写入，Agent查看字形、字高、重叠和专业符号|
|任务局部暂停|实际文字消失、缺字乱码、专业符号错误；影像缺失导致无法判断目标；对象读取不完整且影响当前工程判断|暂停依赖这些事实的工作并排查，可继续无关工作；不能仅凭字体文件名自动宣称缺字或正常|
|必须保护暂停|图纸/进程/请求身份不符，目标摘要过期，未授权对象/图层/布局/内容变化，对象丢失、文件哈希改变，提交结果不明，保存不能独立核实|保留原请求与证据；查询/重新核验原请求，不重放、不删除日志、不手工解锁、不切换通道绕过|

实现边界：本次代码调整只在单步 save 中容许字体选择字段变化，样式 handle、字宽因子、固定字高、竖排等其他字段仍须一致；字体文件名与解析字形同时丢失仍失败。非 save 的未授权字体变化不适用。几何、文字内容、图层、布局和模型对象集合核验继续保留。可读性不能由样式元数据证明，需 Agent 看图；不得把 warning 当作全面验收。

原失败保存只能通过 SaveFontRecovery 对同一请求重新读取内存、磁盘及哈希后恢复；不重新保存、不改写原提交回执。当前工程恢复及新版原生验证结果另记。

本机更新不等于已对外发布；公开包或其他机器更新须使用对应分发流程。
