# 智能底座命令与能力清单 — v1.1.0-rc.1

[English与完整参数表](COMMAND-CATALOG-v1.1.0-rc.1.md) · [旧版清单](COMMAND-CATALOG-v1.0.0-rc.1.zh-CN.md)

新增能力仍走同一图纸绑定、请求账本、原生事务及读回路线。实机状态以配套验收记录为准，不能把实现当验证。`doctor`／绑定结果的`document_info.foundation_catalog`提供实际操作目录、图层与摘要、文字／尺寸样式；它是绑定时观察，是否允许写入另看writes_enabled。

| CLI（10项） | 用途 |
| --- | --- |
| install | 安装版本化带清单包，核对文件。 |
| start | 启动自有工作副本，默认只读。 |
| doctor | 图纸／进程／插件身份及图层样式目录。 |
| read | 按句柄读取对象、几何、摘要与真实文字尺寸。 |
| query | 按类型／图层／范围过滤分页。 |
| apply | 提交一次有界计划，回应未知查原请求。 |
| save | 整图保存与指定对象独立磁盘核验。 |
| status | 查询原已记录请求。 |
| stop | 关闭自有空闲、已保存、无未决栅栏的图纸。 |
| mcp | 相同底座与账本的MCP入口。 |

MCP仍为每模式8项、共9种：dwg_bind_active_document、dwg_list_layers、dwg_get_entity_properties、dwg_query_entities、dwg_job_get、dwg_job_get_historical、dwg_job_cancel；只读模式另含dwg_inspect_lisp，写模式用dwg_apply_plan替换。取消仅排队任务，历史请求查询范围不扩张，不开放任意上游写命令。

| 计划操作（25项） | 实际能力／边界 |
| --- | --- |
| layer | 新建／复用颜色匹配图层。 |
| set_layer | 摘要保护的颜色、开关、冻结、锁定、出图状态修改；影响该层全部对象。拒绝外参层，当前层和0层不能隐藏。 |
| text_style | 使用已安装字体文件名创建／复用匹配文字样式，不分发字体、不覆盖共用旧样式。 |
| dimension_style | 创建／复用匹配尺寸样式，指定字体、字高、箭头、比例、间隙、精度和分色；其余沿用原生当前样式。 |
| line | 新建直线。 |
| circle | 新建圆。 |
| polyline | 新建二维多段线，顶点可带bulge。 |
| text | 新建单行文字，可选文字样式。 |
| mtext | 新建多行文字，可选文字样式；独立读回actual_width／actual_height，宽度参数不保证单行。 |
| callout | 普通LEADER＋关联MTEXT＋黄色实心点，可指定样式、文字／引线分色、间隙及九种文字附着；BottomRight与当前独立排布器对应。 |
| hatch | 同一计划前序新闭合边界的关联填充。 |
| linear_dimension | 原生线性尺寸，核端点、投影测量值和尺寸线垂直偏移。 |
| aligned_dimension | 原生对齐尺寸。 |
| radial_dimension | 原生半径尺寸，以给定中心／弦点生成，控制真实文字位置。 |
| diameter_dimension | 原生直径尺寸，对侧弦点由中心推导。半径／直径不是旧圆的实时关联尺寸。 |
| set_text | 摘要保护的文字内容修改，不随意改格式。 |
| set_polyline | 3～128个闭合、零宽、WCS二维顶点／bulge修改，至多1个关联填充同步路径，不支持复杂孔洞／布尔。 |
| set_callout | 普通三点引线／关联文字位置修改；改变独立圆点锚点时需带圆／填充完整成员。 |
| set_callout_format | 修改关联引线／文字的样式、字高、宽度、间隙与颜色，保留内容、几何、关联及箭头模式。 |
| move | 原已支持对象／完整标注组平移。 |
| rotate | 零厚／零宽二维直线、圆、文字、普通引线、多段线及完整关联填充组旋转。 |
| scale | 正值整体缩放，文字、间隙与圆点随组缩放；不修改共享样式记录。 |
| copy | 同图深复制受支持完整组，重建关联，保护原对象。 |
| archive | 可恢复归档，包括完整闭合边界／填充组，不等于删除，不开放图块／外参归档。 |
| save | 独立单步整图保存、指定对象磁盘读回及模型／图层／样式保护。 |

参数和数量限制见英文完整表；schema仍为foundation-drawing-plan-v1，units必须metres。16步骤、64对象结果、语义JSON128KiB；复制同时计入原对象与新对象。旧值摘要、句柄、完整关联、请求归属均严格核对。

日常面积小于0.001㎡、位置／尺寸0.001m分别判断，不把面积阈值套作坐标阈值。AutoCAD可能沿同一尺寸线移动代表点，验收实际线偏移及端点，不追代表点沿线坐标。HATCH.Area可能在同次事务中保留旧缓存；当次核边界／实际填充路径／关联，回执明示仍需独立读取真实面积。不能靠面积相等证明位置正确。

MTEXT外包框可能包含整段Width，ActualWidth／ActualHeight与段落框分别判断。有限排布先按实测内容宽度加小量余量收紧段落，再以独立读回的真实外包框做障碍；处理剩余冲突时延长预算不得清零。

后续／未支持：任意代码或Lisp、任意属性、删除清理、MLeader、图块／代理编辑、DIMENSION对象旋转缩放复制、复杂孔洞／布尔、跨图、布局出图外参、未知写入自动解锁、毫米、2022及.NET10宿主认证。共享旧样式覆盖不开放，另建新命名样式。BZYD及两Skill独立维护，不因底座新增命令而重写算法。
