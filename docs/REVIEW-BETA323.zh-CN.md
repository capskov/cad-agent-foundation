# 1.2.0-beta.3.23 多图查阅与保存核验提速

## 实战顺序

1. 查阅多张项目图时，先用本机干净的 DWG 或 DWT 运行 `start-review --no-wait`，再用 `startup-status` 看自有 CAD 进程、弹窗线索及插件发现状态。先由底座确认宿主可用，再在该进程中逐张以只读打开项目图。保留一个进程，逐张关闭已读文档。最后回到底座启动图，正常执行 `stop`。
2. 用完整路径绑定。已明确布局、对象类型或图层时，直接查询该范围。对一张图的独立查询合并为 `query-batch`，一次最多 16 项，共用一次程序完整性检查、服务器启动及绑定。大图逐页继续。避免逐实体 COM 循环，也避免为同一张图的多个布局重复启动 CAD。
3. 缺 SHX 时，先判断是否是打开图纸的模态提示，保留当前进程。普通文字缺字优先使用英文数字主字体 `HZTXT_E.shx` 和中文大字体 `HZTXT.shx`。形文件和线型符号先识别用途，再看图确认。FONTALT 只代表单个备用主字体。运行包不分发 SHX，沿用本机字体目录。
4. 改图使用授权工作副本。套框前先定工程范围和实际图幅，再用代表性平面、纵断和详图校验纸幅、比例、字体与 PDF。有效图幅确定后批量套框，由图幅清单反写目录。一个 DWG 的连续布局操作复用会话。

## 修复范围

- `start-review` 使用干净来源启动只读会话。普通 `start` 继续支持旧工作副本入口。两种入口都支持 `--no-wait`，可随后检查 `startup-status`。系统弹窗是窗口观测结果，具体原因须结合标题或 CAD 界面判断。
- `--read-target` 仅支持只读会话中的 `doctor`、`read`、`query` 和 `query-batch`。每次绑定验证进程、插件和绝对图纸路径，附加目标须由 CAD 确认只读。
- 保存核验中用于比较块定义的字体差异按一次核验计算。没有字体变化时直接比较，不逐块克隆数据。原有图纸身份、写入保护和原请求续查规则继续生效。
- 较早的 256 命名块上限在 beta.3.22 已扩大至 4096。这版保留原有核验范围。大图命名块按操作收窄、外参缓存和真实本地符号的分级、创建布局／附着外参／创建工作视口仍需单独的原生契约及真实图纸回归。

## beta.3.24 跨分支采纳

- `layers` 直接调用既有图层读取接口。先查图层名称，再对目标空间、图层及范围查询；两者都支持只读会话的 `--read-target`。
- 对单个句柄的嵌套几何，`read --geometry-offset N` 接收上一页的 `geometry_read.next_offset`。继续读前核对同一图纸会话、修订和实体摘要，并检查问题列表及截断标记。分页无法扩展原生遍历预算。
- `set_polyline` 的 `vertices` 使用二维数组，例如 `[[0,0],[10,0],[10,5]]`。密集轮廓先保留转角和曲线需要的精度，再定点数。大型计划若需增加预算，应同时构建并验证服务端和插件。
- 空间查询遇无法计算范围的对象时，2026 版继续报告错误。后续若引入部分结果，需带遗漏标志和可定向复查的句柄，避免把少读对象误判为没有对象。
