# v1.1.0-rc.1 — Native operations and Windows runtime preview

Adds bounded native DIMENSION (linear/aligned/radius/diameter), installed-font text/dimension styles, layer state management, closed-boundary/single-hatch continuation, linked callout pose/format and supported same-drawing rotate/scale/copy. Keeps explicit drawing identity, fresh old-value digests, complete associations, native transaction/readback, durable original-request queries and whole-document save with independent disk verification.

Provides a manifest-bearing Windows runtime ZIP, SHA256SUMS.txt and dependency notices; Autodesk assemblies, engineering DWGs, SHX fonts, credentials, journals and PDBs are excluded. Prerequisites: licensed compatible AutoCAD 2026 R25.1.74.0.0/.NET8 on Windows x64 and Python3.11+. Separate Skills remain optional for basic CAD and independently maintained. Domain engineering and finite placement algorithm stay in Skills.

Validation: scoped synthetic native workflow and 17-object saved-DWG reopen, packaged MCP/native dimension/layer read, stale-digest/missing-association/locked-layer refusals, unchanged-Skill solver/native integration, offline contracts and final package integrity. See the versioned command catalog and acceptance summary. Prior rc.1/rc.2 tags/releases and stable local packages are retained.

Limits: model-space metre coordinates, bounded entity types/groups, no arbitrary code, unknown-write replay/unlock, block/proxy/DIMENSION transforms, generic deletion, complex-hole/Boolean repair, cross-DWG, layout/plot/xref, millimetres or 2022/.NET10 certification. Hatch cached area requires independent read; equal area does not prove position. No comparative speed or token saving claim.
