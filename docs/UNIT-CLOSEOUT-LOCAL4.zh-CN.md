# 1.2.0-local.4 单位处理收尾（2026-10-16）

本轮在1.2.0-local.3基础上收尾普通CAD操作的单位处理，仅本地交付，未发布GitHub Release。单位用于辅助Agent理解图纸、判断精度及制图方式；普通操作执行DWG原始数值。[完整单位与文字指导](DRAWING-UNITS-AND-TYPOGRAPHY.zh-CN.md)。

## 实际修改

- `FoundationDrawingPlan`：原单位计划的`expected_insunits`改为可选；填写时仍验证整数0..24。新增共用一致性判断，供原生执行使用。
- `FoundationPlanWriteHandler`：事务前及锁内仅执行任务显式要求的单位核对；省略时未知/无单位不挡普通原坐标操作。旧`units: metres`保留INSUNITS=0或6行为，坐标不换算。未修改身份、请求、旧值摘要、事务、未知写入保护。
- `client/foundation.py`：保存入口统一生成`raw_drawing_units`计划，不按元数据选择模式或自动附加单位条件。
- MCP初始化说明、写入工具说明和原生目录明确单位属于辅助元数据，并公开可选检查语义。
- 项目/工作区AGENTS、README、快速入门及组件说明同步原单位原则；运行包新增项目AGENTS.md，让Agent在使用包时也能取得单位、精度和纸面文字指导。
- 插件及服务端本地版本升级为1.2.0-local.4；复用现有契约、入口保护和原生回归脚本。合成图准备函数仅增加0/4/6单位参数。

## 精度检查结论

检查了常见创建、移动、复制、文字、标注、填充和保存路径的绝对数值比较。常用读回位置/长度界限0.001为绘图单位，面积比较界限0.001为平方绘图单位；角度、倍率等沿用专用阈值，不能将其统一称为米或工程允许误差。

米制样例坐标约1000、毫米制样例坐标约1000000，分别验证5与5000的尺寸测量、12与12000000的边界面积以及3毫米量级文字的原始高度。没有发现本轮必须修改的数值计算/读回缺陷，因此没有改写几何算法或引入单位驱动的容差规则。工程验收偏差仍由用户、专业Skill或Agent按任务选择；这不构成极端数值、所有几何组合或所有专业精度的认证。

普通汉字纸面2.5～3.5mm、小于2mm重点检查作为默认指导；用户或Skill要求优先，Agent按实际图框/纸张/打印比例反算，比例服务清晰表达并保持工程尺寸和正式比例正确。不新增自动字体排版、单位推断或比例计算引擎。
