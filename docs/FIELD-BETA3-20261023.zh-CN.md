# 1.2.0-beta.3 本地实战迭代

来自R2/R3人工示教后的道路描边实战。只修基础操作，不在底座加入道路识别规则。

- 多段线原生事实补充constant_width及各顶点start_width/end_width，修复显式固定线宽计划在提交前核验回滚的问题。变宽多段线的常宽读取遇原生InvalidInput时返回null，分段宽度仍明确返回。事实变换计算同步处理宽度，但原生scale/rotate/copy配置仍只支持零宽2D实体；非零宽变换保持提交前无效果拒绝，不借修复扩大范围。摘要格式改变，旧摘要不能跨版本复用，必须重新读取。
- 原生预览截图之后再重绘并更新编辑器屏幕，增加post_capture_regen_completed。此前PNG可能完整但交互窗口显示旧影像瓦片；本次尝试恢复预览后的窗口显示，不将API成功当作瓦片稳定保证。display_settle_verified继续为false。
- 继续使用dwg_view的window/center/read/capture完成放缩、平移和查看。切换中心实现平移，改变height实现围绕中心的放缩，无任意命令入口。

没有放宽当前层不得隐藏、图纸身份、未知写入不重放或保存核验等边界。human为当前层时隐藏失败属原生保护，正确处理是明确切换到审阅层后再隐藏参考线；参考线实体不应被删除。

离线101项契约通过，插件和服务端构建通过；保留既有Roslyn/WebClient警告。打包MCP在工程自有副本通过7条0.08常宽多段线创建/独立读回、非零宽变换无效果拒绝、轻量摘要、连续中心/视高放缩和平移、窗口截图及保存磁盘核验。人工黄线与影像事实未变。

进一步在同一beta.3会话读取10个人工对象、添加交流编号和中心辅助线，保存核验通过；多次视图切换后已实际观察CAD窗口完整显示影像与标注。该观察仅覆盖当前AutoCAD2026/显卡/影像场景，display_settle_verified仍为false。没有对任意影像/驱动承诺稳定。

截图file_name当前只允许ASCII新PNG basename（例如r4_teaching_0.png），输出限定在工作DWG的outputs内；中文名称会在入队前明确拒绝。窗口范围/center可反复调用实现平移和放缩，read返回当前范围；调用方应据画面改变决定何时扩大观察范围，底座不决定道路判断。

最终运行包冻结时不改已实测的二进制；本地交接给出准确MVID、SHA及回退入口。实战仍属有限范围验证，不代表全面产品验收或公开发布。
