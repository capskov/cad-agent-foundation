# 实测性能与比较范围

底座通过加载在 AutoCAD 进程内的 .NET 插件调用原生图形数据库与事务。一次计划可组合多项原生操作并回读指定对象。受控会话还能跨多轮任务复用，省去重复启动、加载插件和打开图纸。直接 COM 路径也能完成专业制图；本案例两条执行路径的数据如下。

| 案例及计时边界 | 底座 | U-C4N COM |
| --- | ---: | ---: |
| 同一张 A1 土建图的同范围成果，三条既有多段线归层、纸空间图例和指北针，初次交付 | 冷启动至绑定 29.20 秒；后续绑定、改图、保存及另存读回 29.59 秒，合计约 59 秒 | 工具会话分段合计约 3 分 46 秒；后续位置调整另约 41 秒 |
| 最终位置复跑中的底座子阶段 | 改图及事务读回 5.292 秒，保存 7.926 秒；保存状态恢复后另存及验证 5.677 秒 | 三条多段线的归层接口 64.634 秒；与左列整个批次边界不同 |

该案例采用 Windows x64、AutoCAD 2026、本地文件及 beta.3.26 候选。底座交付 DWG 为 4,290,469 字节，跟踪 9 条既有占地边界及新建的图例、指北针。后续 beta.3.30 候选另有约 2.28 MB 占地图实测，并在同一受控会话完成多轮 CAD 标注、保存和 A1 PDF。这些是样本规模，不是性能上限。两条路线的编排、冷启动和最终验证范围有所不同，案例中的耗时差不能直接视作通用倍数，也不代表所有 MCP 或 COM 工具的表现。

下载时间需要针对公开资产、网络和测量地点独立实测。目前没有可归因于本候选公开下载的计时。本地复制、解包、AutoCAD 启动时间不能计作下载。
