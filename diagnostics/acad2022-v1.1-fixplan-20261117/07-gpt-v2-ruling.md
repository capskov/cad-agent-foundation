## 一、六条正式裁决

### 1. INSUNITS：放宽到 0 / 4 / 6，不做自动换算
- 允许 `INSUNITS = 0（无单位）/ 4（毫米）/ 6（米）`。
- **不得自动缩放坐标**；`INSUNITS=0` 保留"单位未明确"状态，不得擅自认定为米。
- plan 可带可选字段 `expected_insunits`，用于校验实际图纸单位是否符合预期。
- DXF 导出后重新读取，核对坐标、标注量值与单位元数据；元数据缺失给警告。

### 2. 构建基线：必须强制同源
- 长期统一为：GitHub 指定 commit 为唯一可信源码 → 构建工作区从该 commit 检出 → 评审工作区同 commit 只读。
- Release Manifest 必须包含：源码 commit + 输入文件摘要 + DLL SHA256 + 构建环境。
- 源码摘要算法：按排序后的相对路径 + 文件内容计算 SHA256，**不计文件 mtime**；
  输入除 `.cs`/`.csproj` 外还需包含 `.props`/`.targets`/依赖锁定文件/资源。
- 当前 `src\cad-agent-foundation-main` 无 git 版本管理，暂可作可信构建源，但必须核定后纳入版本管理。

### 3. D5 恢复语义（实质修改原方案）
| 命令 | 允许 | 禁止 |
|---|---|---|
| `resolve --inspect` | 只读查看请求、两份回执、磁盘与事务状态 | 修改任何状态 |
| `resolve --recover` | 核对磁盘文件/句柄/哈希/原请求/账本，证据一致后恢复可信状态 | 重放写入、直接把磁盘文件当成功 |
| `resolve --discard` | 放弃当前 revision，保留现场，从可信版本新建 revision | 清除历史、无条件解锁工作区 |

- `--recover` 必须证明读到的版本**确实来自该次请求**，不能"重读磁盘就宣布成功"。
- 先查现有 SQLite 账本里是否已保存 `verification_result_json`；有就不必为取证重跑危险的 set_text。
  → 已查到，见 `08-d5-rootcause-evidence.md`。
