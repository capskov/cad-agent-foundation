## 任务上下文（为什么会有这些缺陷）

- 底座：`releases/ACAD2022-V1.1-Preview`，运行时 CLI 子命令 install/start/apply/read/save/stop/status/mcp/view/plot-style
- 计划 schema：`foundation-drawing-plan-v1`，`units=raw_drawing_units`，上限 16 步 / 64 句柄 / 128 KiB
- 出图任务需要的能力：图层、折线（带恒宽做管道带宽）、圆、文字、线性标注、块/填充（未用到）
- 实际卡点：**尺寸标注完全用不了**、**原地改字把工作区锁死**、**提交/会话生命周期脆弱**

## 结论摘要（一句话版）

底座的几何生成能力是可靠的（20 余次 apply 里 17 次 `committed_verified`），
但**标注能力（D1）与写入事务的失败语义（D2/D3/D5）是当前最大的两处硬伤**，
其中 D1 直接决定后续所有"能出施工图"的任务能不能做。
