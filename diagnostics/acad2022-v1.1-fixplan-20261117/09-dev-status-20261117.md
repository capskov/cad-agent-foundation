## 四、验收结果（全部为真实 AutoCAD 2022 隔离实测）

### P0-A-1 D8 元数据核查 + 修复 → 通过
见 `01-defects.md` 的 D8 节（已重写）：三个 DXF 方法在运行 DLL 元数据里都在，"装配缺口"是误判；
真因是 INSUNITS 门槛。修复后 `d5fix-03` 导出成功，`$INSUNITS=4` 保留，receipt 记
`insunits=4 / millimetres / disk_readback=4 / coordinate_scaling=none`；负向（全 0 指纹）被拒且不产文件。

### P0-A-2 INSUNITS 只读检查 → 通过
交付图 `三管共用闸阀井_内部评审版V4.dwg` 为 `INSUNITS=4`（毫米），按裁决允许 0/4/6 且不换算。

### P0-A-3 D2 两组受控实验 → 通过，D2 关闭
- **实验 A（拒绝不留 fence）**：`d5fix-03` 提交全 0 指纹的 export plan → `failed / no_effect_terminal`；
  随后 `server.write_fences = 0`、`native.plugin_write_fences = 0`；再提交合法 export plan → `committed_verified`。
  → 拒绝不产生悬挂 fence，也不影响后续写入。
- **实验 B（原 fence 归属不被污染）**：`d2b-02`（`--write --allow-save`，故意不 `--save-to`）
  合法 `set_text` → `committed_verification_pending`、`pending=true`、`write_fence_released=false`，
  `request_jobs` 里 `d2b-02a` 持有 `risk_keys_json=["PATH:F:\...\D2B-02\DR..."]`、`write_fence_released=0`；
  随后提交非法 plan → `rejected_before_submission`，且 **`d2b-02b` 在 ledger 里完全不存在（无行）**。
  → 非法请求既不夺取也不释放原 fence；`stop` 仍返回 `Unresolved write fence: {'native': 1, 'server': 1}`，
  安全阻断按设计生效。
- 结论：D2 是**正常保护**，不是泄漏。关闭，不再继续调查。

### P0-B D5 根因修复 + 真实 CAD 闭环 → 通过（核心成果）

### P0-B 顺带修掉的两个启动缺陷 → 通过
1. `save_drawing` 未纳入启动 reconcile 写入白名单 → 任何 apply+save 后重启都 fail-closed。
   修法：写入分支识别 `FoundationSaveRequest.Plugin` + canonical 校验。
2. 已释放 fence 的行被 `recoveredStage/currentStage` 门槛挡住。修法：加 `releasedStage` 分支，
   行仍由 digest / validator_version / sequence 校验兜住。
   验证：`d5fix-02` 重启后 server 正常 initialize 并进入绑定阶段（不再抛 fail-closed）。
   实测暴露的新错误变成 `drawing_path_mismatch`——即启动 reconcile 已过，卡在图纸身份绑定。

## 五、当前阻断发布的问题（按优先级）

1. **P1 / D6：一图一保存身份绑定**。`apply --save-to` 是 Save-As，活动文档路径变为
   `outputs\work-d5-02.dwg`，而 session 期望原 `work.dwg`，于是后续任何 CLI（含 `read`/`stop`）都报
   `drawing_path_mismatch`。**这是"保存后连续修改"唯一现实拦路点**，需要 revision 生命周期策略：
   save 后自动重绑并刷新 `session["drawing"]`，或显式要求新工作区。本轮未改（属架构级）。
2. **P0-C / D1：标注未打通**。`dimension_style` 必填但报错信息差，6 条原生 DIMENSION 实测未做。

4. 通用 `dwg_export_dxf` 是否加 `expected_insunits`，待两条导出路径语义对齐。
5. 源码治理：实际构建源现已在本地 git（`ac2f0d8`），但**尚未推到 GitHub**（属新仓库，需单独建远端），
