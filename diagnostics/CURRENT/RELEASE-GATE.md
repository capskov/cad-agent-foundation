# 2022 内测预览版发布门禁

更新：2026-11-16  
分支：`acad2022-v1.1-diagnostics`  
判断对象：ACAD2022 V1.1 智能底座 + `cad-callout-pair-layout` 2022 版 Skill  
结论：**可以封“2022 内测预览版”，但不能封“生产默认版”。**

本文件只做发布判断，不做修复完成声明。预览版允许带已知限制，但必须把限制写进发布说明；生产默认版不允许把未验证终态、可见残留或未定义专业口径写成“已支持”。

---

## 1. 两种版本的口径

| 版本 | 允许范围 | 不允许的范围 |
| --- | --- | --- |
| 2022 内测预览版 | 隔离测试图、合成样例、受控试用；允许人工复核和明确限制 | 真实生产工程图、无人值守批量出图、对外宣称“生产默认” |
| 2022 生产默认版 | 真实工程图；旧标注清理、SaveAs 连续会话、页面设置终态、负向回归均可验收 | 已知可见残留未清、终态未确认、专业口径未定 |

## 3. 首版（内测预览版）前必须完成

1. **证据清单与实际文件一致**：`CURRENT/evidence-gap-third/` 必须同时包含 PDF、两张 DWG、三张预览图和四个日志；`SIZES-SHA256.txt` 的 20 行必须逐项命中。本次提交已补齐。
2. **当前源码可审查**：`CURRENT/source-v1.1/` 必须含当前 `client/foundation.py`、`client/plot_style.py`、`server.json`、构建 `manifest.json` 和源码清单；顶层旧 `client/foundation.py` 不得再被当作当前版本。本次提交已补齐。
3. **D-02 证据可读**：`CURRENT/evidence-d02/` 必须含最小脱敏请求/响应和三项负向回归；不得只给结论。本次提交已补齐。
4. **发布说明写清限制**：至少写明“SaveAs 后需换新工作区”“page_setup 未 finalize”“旧标注是归档不是物理删除”“砖墙图为合成样例，不作为施工图”“370 放脚标高待专业确认”。
5. **不得改判**：不得把 PDF `committed_verified` 写成页面设置通过；不得把文件存在写成 finalize 通过；不得把用户主动终止写成 CAD 崩溃。

## 4. 生产默认版前必须解决

| 项 | 原因 |
| --- | --- |
| `OPEN-05` SaveAs 连续会话 | 长任务被切成多个工作区，不能作为生产连续作业 |
| `OPEN-06` page_setup finalize | PDF 可打印不等于页面设置自身闭环 |
| `OPEN-02` 2 个旧圆点残留 | 真实图面可能有可见残留，不能宣称“旧标注全部清理” |
| `OPEN-10` 负向回归缺口 | D-02、P1-A、P1-B、P2-C/P2-D 未跑完，生产评审不可接受 |
| `OPEN-11` 生产字体路径 | PID 12948 未重启，`F:\fonts` 在生产会话是否生效未验证 |
| `OPEN-12` 1/3 字高口径 | 名义字高与实际格式化高度不一致时，规则没有唯一解 |
| `OPEN-13` 370 放脚标高 | 400 mm 放脚全在地面以上，是否符合专业意图未确认 |
| `OPEN-01` 物理删除策略 | 若生产要求“删除”而不是“归档”，当前只有 archive，没有安全 erase |
